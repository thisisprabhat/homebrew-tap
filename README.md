# homebrew-tap

Homebrew tap for [Sweepkey](https://github.com/thisisprabhat/sweepkey).

```sh
brew install --cask thisisprabhat/tap/sweepkey
```

The 0.1.0 build is not yet signed or notarized. If macOS blocks the first launch, right-click the app and choose Open, or run `xattr -dr com.apple.quarantine /Applications/Sweepkey.app`.
